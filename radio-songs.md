# World Drive Radio: song prompts

How to use in Suno: Custom mode. Paste the **Style** line into Style, paste the **lyrics** into Lyrics,
and use the title as the song's name. Leave Instrumental off.

Seven songs have full lyrics (one per station). The rest have a title, a style and an idea:
generate their lyrics in Suno from the idea, or ask Claude to write them.

## Tips

- Suno songs run about 2–4 minutes. To make one longer, use **Extend** in Suno.
- Put the station name in a song's lyrics now and then (for example "you're on Sunset FM" in an
  intro) so the songs sound like they belong to the station.
- Jingles: if Suno makes them too long, trim them to the first few seconds.
